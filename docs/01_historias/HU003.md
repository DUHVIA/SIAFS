### Descripción
* **Como** usuario del sistema
* **Quiero** buscar productos (motores o autopartes) por nombre, categoría o estado de stock
* **Para** dar respuestas rápidas a los clientes sobre la disponibilidad.

### Criterios de Aceptación
1. El buscador debe filtrar resultados en tiempo real por nombre o categoría sin necesidad de presionar "Enter" o un botón de búsqueda.
2. Los productos con stock igual a 0 deben mostrarse con un indicador visual (ej. texto rojo "Agotado").

### Notas Técnicas (Opcional)
* Implementar Debounce (retraso de 300ms) en el input de búsqueda del Frontend para no saturar la base de datos con consultas por cada letra tecleada.
