### Descripción
* **Como** administrador del sistema
* **Quiero** registrar un nuevo motor (especificando marcas compatibles, estado, tipo de combustible, precio y stock inicial)
* **Para** poder cotizar este tipo de componentes complejos correctamente.

### Criterios de Aceptación
1. Debe validar campos obligatorios (nombre, marcas, estado, combustible, precio, stock).
2. Debe permitir agregar más de una marca compatible al motor.

### Notas Técnicas (Opcional)
* Guardar detalles específicos en la misma columna JSONB. Usar un array de strings para las marcas.
