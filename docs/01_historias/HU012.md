### Descripción
* **Como** vendedor
* **Quiero** exportar una cotización a formato PDF
* **Para** poder imprimírsela al cliente o enviársela digitalmente.

### Criterios de Aceptación
1. El PDF debe incluir: Logo del taller (Duhvia lo puede diseñar), datos del cliente, lista de productos, total y fecha de validez.

### Notas Técnicas (Opcional)
* Pueden usar la librería @react-pdf/renderer o jspdf en el Frontend para generar el documento.
* Formato de documento de cotizacion: CONSULTAR. (El cliente menciono que actualmente lo hace en canva).
