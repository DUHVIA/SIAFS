## HU-025: Importar datos de productos apartir de una plantilla

### Descripción
* **Como** administrador del sistema
* **Quiero** importar datos de mis productos apartir de una plantilla 
* **Para** agregar inmediatamente mis productos al sistema.

### Criterios de Aceptación
1. El sistema debe de proporcionar una plantilla previo a la importacion de datos.
2. Al importar el archivo el sistema debe de agregar los nuevos productos a lista de inventario.
