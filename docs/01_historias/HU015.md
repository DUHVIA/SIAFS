## HU-015: Convertir cotización a Venta

| **Estado** | Por hacer |

### Descripción
* **Como** vendedor
* **Quiero** convertir una cotización "Pendiente" a estado "Venta" registrando el método de pago
* **Para** concretar el negocio y que el sistema descuente el stock automáticamente.

### Criterios de Aceptación
1. Debe requerir que el usuario seleccione el método de pago (Efectivo, Tarjeta, Yape/Plin).
2. Al confirmar, el estado cambia a VENTA y el stock de cada producto involucrado se reduce automáticamente en la BD.

### Notas Técnicas (Opcional)
* ¡Crítico! Esto debe ejecutarse en una Transacción SQL (Database Transaction). Si falla la reducción de stock de un ítem, no se debe registrar la venta.
