### Descripción
* **Como** vendedor
* **Quiero** crear una cotización seleccionando productos, cantidades y un cliente
* **Para** registrar la intención de compra y congelar un precio base.

### Criterios de Aceptación
1. Debe permitir seleccionar un cliente existente y agregar N cantidad de productos.
2. El sistema debe calcular automáticamente el Subtotal y el Total a medida que se cambian las cantidades.
