### Descripción
* **Como** administrador del sistema
* **Quiero** crear nuevas cuentas de usuario y asignarles un rol (Dueño, Admin, Vendedor)
* **Para** garantizar que cada quien acceda solo a las funciones permitidas.

### Criterios de Aceptación
1. El sistema debe soportar roles: Dueño (acceso total), Admin (gestión inventario), Vendedor (solo ventas/cotizaciones).

### Notas Técnicas (Opcional)
* Para la autenticación en Next.js, la forma más rápida y segura es implementar NextAuth.js (Auth.js).
